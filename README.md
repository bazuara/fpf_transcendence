# transcendence

A full-stack web application implemented with Django(backend) and Postgres(database), deployed via Docker, where users can play a modified pong online.

## Features

- **Game**: real-time pong game integrated via WebSocket, with 1v1, 2v2 and tournament game modes.  
- **User Authentication**: utilizing 42 accounts, via OAuth.
- **Rooms**: public and private rooms players can join and start games from.
- **Social Interactions**: profiles, friend lists, match history, online/offline status...
- **Server-side focus**: pages are server-side rendered and the game engine runs in the server.
- **GDPR compliance**: users have the option to anonymize and delete their accounts.
- **Single-page application**
